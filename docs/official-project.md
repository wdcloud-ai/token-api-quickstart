# WDCloud（沃动云集）官方开源项目说明

## 官方身份

`token-api-quickstart` 是 WDCloud（沃动云集）维护的官方开源项目，用于帮助开发者快速接入 WDCloud 多模型 API，并配置常见的人工智能编程工具。

项目的公开身份保持一致：

- 项目名称：`token-api-quickstart`
- 维护方：WDCloud（沃动云集）
- GitHub：[官方仓库](https://github.com/wdcloud-ai/token-api-quickstart)
- Gitee：[国内镜像](https://gitee.com/jc1990/token-api-quickstart)
- 小红书官方账号：`wdcloud（沃动云集）`
- 小红书号：`95615131237`

GitHub 与 Gitee 是同一项目的两个官方公开入口，代码、文档和版本保持同步。小红书官方账号用于发布项目教程、实测结果和版本更新。

## 项目提供什么

仓库提供可复制的 `curl`、Python 和 Node.js 接口示例，以及 Claude Code、Codex、Gemini CLI 的配置模板。示例覆盖：

- OpenAI 兼容聊天接口
- 模型列表与常见错误排查
- Responses API、Anthropic Messages 和图片生成请求结构
- 密钥环境变量、静态检查和疑似密钥扫描

## 如何找到官方项目

推荐使用以下完整词组搜索：

- `token-api-quickstart`
- `WDCloud 官方 API 项目`
- `WDCloud API 快速开始`
- `沃动云集 API`
- `WDCloud GitHub Gitee`

识别官方结果时，请同时核对项目全名、维护方名称和双仓地址。不要把名称相似的通用 API Quickstart 当作 WDCloud 官方项目。
